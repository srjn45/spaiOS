# Task: Wake Word Detection

**Date:** 2026-04-27
**Phase:** Phase 2 — The Reach
**Session goal:** Add always-on wake word detection so saying "hey spaiOS" shows the overlay and starts recording, with 1.5s silence ending the utterance.
**Notion task ID:** phase2_m1_voice_pipeline

## What We're Building

A background `WakeWordListener` QThread that runs vosk continuously and fires signals when the wake phrase is detected and when 1.5s of post-wake silence marks end of utterance. Also adds a mic privacy dot to the overlay and auto-downloads the vosk small model (~40MB) on first run.

## Approach

1. Write failing tests for `is_wake_phrase` and `SilenceDetector`
2. Add `vosk` to `pyproject.toml`; run `uv sync`
3. Implement pure functions (`is_wake_phrase`, `SilenceDetector`, `vosk_model_path`, `ensure_vosk_model`) in `voice.py`
4. Implement `WakeWordListener(QThread)` with `wake` and `utterance_end` signals
5. Add mic privacy indicator dot to overlay (shown when `WakeWordListener` is running)
6. Wire `WakeWordListener` in `main.py` — show overlay + start recording on `wake`, transcribe on `utterance_end`
7. Manual test: say "hey spaiOS, what time is it?" without touching keyboard
