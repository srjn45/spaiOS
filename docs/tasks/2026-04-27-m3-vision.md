# Task: M3 Session 7 — Screen Capture + Vision Toggle

**Date:** 2026-04-27
**Phase:** Phase 1 — Milestone 3, Session 7
**Session goal:** Capture the active window as JPEG and feed it to moondream via a camera toggle in the overlay.
**Notion task ID:** 34e7600e54c781da8290e0c96c87ea64

## What We're Building

A camera toggle button in the overlay's input row. When active, pressing submit captures the full screen as JPEG bytes, base64-encodes it, and sends it to moondream alongside the text prompt. When inactive, text-only `AskThread` is used as before.

Using `mss` for screen capture and `moondream:latest` (already installed, 1.7GB — fits VRAM).

## Approach

1. `src/spaiOS/core/screen_capture.py` — `capture_jpeg() -> bytes` using `mss`; returns JPEG bytes of monitor 1
2. `src/spaiOS/core/orchestrator.py` — add `AskWithVisionThread(prompt, image_bytes)` using moondream
3. `src/spaiOS/ui/components.py` — add `camera_active` property + camera toggle `QPushButton` to `InputRow`
4. `src/spaiOS/ui/overlay.py` — wire toggle: if active, capture + `AskWithVisionThread`; else `AskThread`
5. Test: activate overlay, toggle camera on, ask "what do you see?" — moondream describes screen
