# Task: Phase 2 M1 — Voice Push-to-Talk

**Date:** 2026-04-27
**Phase:** Phase 2 — The Reach
**Session goal:** Get faster-whisper transcription working end-to-end: Super+Shift+Space toggles recording, transcript feeds into Orchestrator.
**Notion task ID:** phase2_m1_voice_pipeline

## What We're Building

Push-to-talk voice input for the overlay. First press of Super+Shift+Space starts microphone
recording (sphere goes green/"listening"). Second press stops recording, transcribes via
faster-whisper, and submits the transcript to the Orchestrator exactly as if the user had typed it.

## Approach

1. Add `faster-whisper` and `sounddevice` to `pyproject.toml`
2. Add `SPHERE_LISTENING_COLOR` (green) to `tokens.py`
3. Add `"listening"` state to `neural_sphere.py`
4. Implement `src/spaiOS/core/voice.py` — `VoiceRecorder` + `VoiceTranscribeThread`
5. Update `hotkey.py` to accept optional `voice_fn` and register `<cmd>+<shift>+<space>`
6. Add `toggle_voice()` slot to `overlay.py`; wire voice result → `_on_prompt_submitted`
7. Wire everything in `main.py`

## Files Touched

- `pyproject.toml` — new deps

## System prerequisite

```bash
sudo apt install portaudio19-dev
```

faster-whisper downloads the `tiny` Whisper model (~75MB) to ~/.cache on first transcription.

## Done When

1. `Super+Shift+Space` → sphere turns green, response view shows "Listening…"
2. Second press → sphere shows "Transcribing…", then "Thinking…"
3. Transcript appears as the submitted prompt, AI responds normally
4. Empty recording (no speech) → friendly error, input re-enabled
5. lint passes, committed
